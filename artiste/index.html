    Nouvelle œuvre

    Utilisez le même fichier que le tirage exposé. Les photos riches en détails sont mieux reconnues que les grands aplats (ciel uni, brouillard).

    Effets

    Mettre en ligne

    1. Préparer le dossier de l'exposition

      Le site apprend à reconnaître chaque photo et rassemble tout dans un fichier « exposition.zip ».

    2. Le déposer sur GitHub

      Décompressez « exposition.zip » : vous obtenez un dossier « expo ». Ouvrez la page de dépôt, glissez-y ce dossier, puis cliquez sur le bouton vert « Commit changes ».

      Ouvrir la page de dépôt GitHub

      Ouvrez votre projet sur GitHub, puis « Add file » et « Upload files ».

    3. Vérifier

      Après 1 à 2 minutes, ouvrez le lien des visiteurs ci-dessous : votre exposition y apparaît.

    Le lien des visiteurs

    Imprimez ce QR code à l'entrée de l'exposition ou à côté des photos.
